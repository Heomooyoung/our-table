# 우리집 식탁 (Our Table)

가족의 "오늘 뭐 먹지?"를 끝내기 위한 우리집 메뉴판 웹앱. 빌드 없이 돌아가는 **단일 HTML 파일**(`index.html`)이다.

## 뭘 하는 앱인가

- **우리집 메뉴판** — 맛있게 먹은 메뉴를 기록. 이름 한 줄만 적어도 등록되고, 재료(양·브랜드·사진)·만드는 법·메모는 선택. 베스트(하트×해먹은 횟수)가 메뉴판 상단에 보인다.
- **주간 식단표** — 메뉴판에서 골라 요일·끼니에 배치.
- **장보기 리스트** — 식단표에 넣은 메뉴들의 재료가 주 단위로 자동 취합. 같은 재료는 합치되 양은 "2큰술 · 샌드위치"처럼 출처별로 표기(자유 텍스트 양을 억지로 더하지 않는다).
- **오늘 뭐 먹지** — 카드 뽑기 / 사다리 타기 / 가족 투표(한 폰을 돌려가며 비밀투표, 배달 찬스 후보 포함). 결정하면 오늘 식단표에 자동 반영.

## 실행

`index.html`을 브라우저로 열면 끝. 별도 서버·빌드 불필요.

- **주소: https://uritable.vercel.app** (Vercel · main에 push하면 자동 배포)
- 구주소: https://heomooyoung.github.io/our-table/
- 로컬 미러(Claude Artifact): https://claude.ai/code/artifact/a928241d-850a-433e-a9c8-2e716c3bb2aa
- 데이터는 브라우저 IndexedDB에 저장(기기별) + 로그인하면 Supabase로 가족 간 실시간 동기화.
- 테스터 접속 확인: 주소 끝에 `#log` (만든 사람만 보임 — 설정 방법은 `DEPLOY.md` 2-2)

## 시작하는 흐름

고를 것을 없앴다. 로그인이 유일한 입구다.

```
나        카카오/구글 로그인 → 우리집이 자동으로 생김 → 초대 링크 보내기
가족      링크 열기 → 카카오/구글 로그인 → 그 집에 자동 합류
```

초대 코드를 받아적거나, "새로 만들까 합류할까"를 고르거나, "이 폰에만 쓸까"를
정하는 화면은 없다. 이름은 카카오·구글 프로필에서 가져오고 첫 화면에서 바로 고칠 수 있다.
(코드는 링크가 안 열릴 때를 위해 설정에 남아 있다.)

## 개발일지 — 커밋할 때 같이 쓴다 (정책)

**커밋 하나 = 일지 한 문단.** 나중에 몰아 쓰지 않는다. 몰아 쓰면 *왜 그렇게 정했는지*가 날아가고, 커밋 메시지만 남아 껍데기가 된다.

- **위치**: `Desktop/옵시디언/업무/20260806 우리집 식탁 앱 개발일지.md`
- **형식**: `## 추가 (MM-DD, vX.Y) — 한 줄 제목` 뒤에 아래 셋
  1. **뭘 바꿨나** — 사용자가 보는 변화로 쓴다. 함수 이름 말고
  2. **왜 그렇게 했나** — 다른 길을 왜 안 골랐는지까지. *이게 제일 중요하다*
  3. **교훈** — 다음에 같은 실수를 피할 한 줄. 없으면 안 써도 된다

- 버그를 고쳤으면 **증상 → 원인 → 왜 늦게 찾았는지**를 남긴다. 원인만 적으면 다음에 또 늦게 찾는다.
- 사장님 지적으로 바뀐 건 **그 말을 그대로 인용**한다. 나중에 읽을 때 맥락이 산다.
- 일이 끝날 때마다 `## 남은 일`을 현재 상태로 맞춘다. 다 한 것이 할 일로 남아 있으면 문서가 거짓말을 시작한다.
- 책 소재가 될 만한 교훈은 `## 오늘의 교훈` 아래 날짜별로 모은다.

> 왜 이 정책이 생겼나: 8월 8일 v3.1에서 일지가 멈춘 채 사흘이 지났고, 그동안 커밋 11개가 쌓였다.
> 되짚어 쓰는 데 시간이 더 들었고, "그때 왜 그렇게 정했는지"는 대화 기록을 뒤져야 나왔다.
