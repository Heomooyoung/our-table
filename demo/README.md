# 데모 데이터 (홍보 촬영용)

스레드·릴스 등에 올릴 스크린샷을 찍을 때만 잠깐 채워 넣는 가짜 데이터입니다.
**앱 코드(`index.html`)에는 이 데이터가 들어 있지 않습니다.** 요청할 때만 이 폴더에서 읽어옵니다.

## 켜기 / 끄기

| 동작 | 방법 |
|---|---|
| 켜기 | 주소 끝에 `#demo` 붙여서 열기 → `https://uritable.vercel.app/#demo` |
| 끄기 | 홈 상단 검은 배너의 **[끄기]** 버튼, 또는 `#demo=off` 로 접속 |

켤 때 원래 데이터를 브라우저에 백업해두고, 끄면 그대로 되돌립니다.
서버(우리집 계정)에는 **아무것도 올라가지 않습니다** — 데모는 그 기기 화면에만 존재합니다.

> 촬영은 로그인하지 않은 상태(게스트)에서 하는 걸 권합니다. 실제 가족 데이터와 섞일 일이 없습니다.

## 무엇이 들어 있나

- 집밥 메뉴 **12가지** — 김치찌개·제육볶음·미역국·잡채·계란말이·김치볶음밥·된장찌개·닭볶음탕·갈비찜·순두부찌개·불고기·콩나물무침
- 각 메뉴마다 실제 사진, 재료(수량·단위), 만드는 법, 우리집 메모, 별점, 해먹은 횟수
- **이번 주 식단표**가 채워진 상태 (지난 이틀 + 오늘~일요일)
- 가족 3명(엄마·아빠·하준), 3인 기준 → 장보기 리스트도 자동으로 채워짐

## 내용 바꾸기

`seed.json` 만 고치면 됩니다. 사진을 추가하려면 `img/` 에 넣고 `"photo": "img/파일명.jpg"` 로 적으세요.
